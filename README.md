# AIGC Vault Mobile

AIGC Vault 的独立手机网页，用于浏览电脑端同步的图片、视频和提示词。支持 Safari 和“添加到主屏幕”独立运行。

**打开网页：[Yonghao87.github.io/jimeng-mobile](https://Yonghao87.github.io/jimeng-mobile/)**

当前界面：**v1.1.1 · 2026-10-30**。手机版独立版本：`1.1.1`。源码标记：`2026-10-29-view06`。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 三种浏览方式

单击顶部浏览方式按钮，依次切换网格 → 大图 → 纯享 → 网格，选择只保存在手机。切换时保留当前作品、已加载范围和图片位置，不跳回列表顶部；适用于画廊、收藏和搜索。

- **网格**：原有多列缩略图，适合快速找内容。顶部模型标签高度压缩为32px。
- **大图**：单列大图，外框跟随当前预览图的实际比例；显示模型、提示词摘要和详情入口，多图左右滑动时同步调整高度。
- **纯享**：外框按当前预览图片的实际比例自适应，多图左右滑动时同步调整高度；尽量只显示图片，隐藏网页内顶栏、底部导航、作品文字与大部分控件，保留多图张数。右上角“菜单”随时恢复导航，再点“收起菜单”继续纯享；下方“退出”回到进入纯享前的视图，并保留浏览位置。浏览器地址栏和手机系统状态栏由系统控制，页面不保证隐藏。


实测比例筛选支持电脑端同步的数据，包含标准比例、横竖方向和接近比例匹配；缓存与撤销状态会在手机同步后更新。

图片关闭原生拖拽，触摸时可直接滑动画面，不会选中后拖动图片。

## 功能

- 浏览即梦、MJ、Nano Banana、GPT Image 等模型内容，图片识别记录有独立入口。
- 默认按最新采集排序，可切换最早采集、最近修改；按今天、近7天、近30天筛选。
- 搜索模型、版本、网站及提示词，最多显示当前排序前60条，并显示匹配总数。关闭详情后返回原搜索结果和位置。
- 按模型、版本、来源网站、媒体、画幅、标签等条件筛选，已选条件可单独移除。
- 查看多图、双语提示词、视频、原始链接，复制提示词；画廊和收藏每批追加40条。
- 按画板浏览，查看电脑端同步的收藏；普通模式显示全部画板，工作模式隐藏电脑端标记的画板。
- 打开时先显示本机已缓存的云端记录，并标注缓存条数和最近同步时间；同步后更新缓存提示。
- 在手机本地新建提示词并导出JSON，随后在电脑端导入。
- 手机两列，较宽屏幕三列或四列，支持横屏。

进入画板后，顶部模型标签仅筛选当前画板中的采集；选择“全部”恢复该画板全部模型。Meigen 多图使用不发送网页来源信息的图片请求，避免原站拒绝外部网页加载。

## 首次使用

1. 在电脑端 AIGC Vault 中完成采集并执行上传同步，生成 COS 索引 `mobile_meta.json`。
2. 确认该索引允许公有读取，图片和视频链接也能由手机访问。
3. 打开本网页，在“设置 → 腾讯云 COS 配置”填写完整 Bucket 名称和地域。
4. 点击“同步数据”，再返回画廊浏览。
5. 可从 Safari 分享菜单选择“添加到主屏幕”。

手机不需要 COS SecretId 或 SecretKey。云端操作仅为GET读取，不上传或修改云端采集、收藏和画板状态。电脑新增内容后，先在电脑上传，再在手机同步。索引公开读取也会公开其中的提示词和媒体链接，请按内容设置访问范围。

## 时间与排序

- 默认“最新采集”，优先使用有效的 `collectTime`，缺失时用 `createdAt`；“最近修改”优先用 `updatedAt`。时间缺失的记录排最后，相同时间保持稳定顺序。
- “近7天”包含今天与前6个手机本地自然日；“近30天”同理。
- 时间范围用于画廊和搜索，收藏沿用排序；画板总数和收藏总数不受时间范围影响。
- 排序和时间范围保存在当前手机站点。分类或筛选变化回到顶部，看详情后返回保留位置。

## 工作模式与隐藏画板


普通模式显示全部画板；工作模式读取 `mobile_meta.json` 中的 `boards[].hidden` 标记，在画廊、搜索、收藏、画板和新建表单画板选项中排除对应内容。

桌面工作模式开关只保存在电脑本机；手机模式选择也只存在手机，不修改电脑与云端。修改隐藏状态后，先在电脑上传同步，再在手机同步。旧索引若只含画板名称，没有隐藏标记，需由当前电脑端重新上传。

隐藏是浏览规则，不会删除云端数据或原始索引缓存；手机不提供更改云端隐藏状态的入口。

## 手机本地新建与数据保存

底部“＋”可新建提示词；图片输入目前接收HTTP/HTTPS链接，每行一张。新建内容保存在当前站点本地存储，不会直接上传COS。

回到电脑端的流程：手机“设置 → 手机端本地记录 → 导出本地记录” → 电脑端导入JSON → 电脑上传同步 → 手机再次同步。导出仅包含手机新建记录，不是整份云端库的备份。

| 内容 | 保存位置 |
| --- | --- |
| 手机新建记录 | localStorage：`aigc_mobile_local` |
| Bucket、地域 | localStorage：`aigc_mobile_cos` |
| 普通/工作模式 | localStorage：`aigc_mobile_work_mode` |
| 排序与时间范围 | localStorage：`aigc_mobile_browse` |
| 云端索引缓存 | IndexedDB：`aigc_mobile_db` / `cache` / `cloud_cache` |
| 云端缓存同步时间 | IndexedDB：`aigc_mobile_db` / `cache` / `cloud_cache_meta` |

每次打开会优先读取已有云端缓存；画廊顶部显示缓存记录数和最近同步时间。旧缓存没有同步时间记录时仍会显示条数。Safari与主屏应用的存储环境可能不同。清除网站数据、迁移域名或更换入口前，先导出手机未回传电脑的本地记录。缓存不等于完整离线媒体包，未缓存的图片和视频仍需联网。

## 仓库更新与发布

本仓库保存已构建的独立手机页面，运行只需要根目录 [index.html](index.html)。README和CHANGELOG用于说明及记录，不是运行依赖。

1. 在开发项目 `aigc-vault` 中执行 `npm run build:mobile`。
2. 将生成的手机HTML作为本仓库根目录 `index.html` 提交，同时更新说明及更新记录。
3. GitHub Pages 使用 `main` 分支根目录发布；在 [Actions](https://github.com/Yonghao87/jimeng-mobile/actions) 确认“pages build and deployment”成功。
4. 手机刷新网页，在“设置 → 关于”核对界面标识。

本次浏览更新沿用已获实机确认的03底栏配置，无需因此重新创建主屏图标。

## iPhone 底栏

当前采用不透明 `black` 系统状态栏、应用容器 `100dvh`、固定底栏和系统底部安全区。此底栏配置已获用户iPhone主屏实测确认，不将屏幕高度强行当作网页高度，也不写死状态栏高度补偿。

## 常见问题


| 现象 | 检查 |
| --- | --- |
| 同步提示403 | 索引公有读权限，以及Bucket、地域是否正确 |
| 同步提示404 | 电脑是否已上传，Bucket中是否有`mobile_meta.json` |
| 仍显示旧页面 | 查看Actions部署状态，刷新后核对设置里的界面标识 |
| 刚采集的内容没出现 | 电脑是否已上传、手机是否已同步、时间和模型筛选是否限制了结果 |
| 隐藏画板仍出现 | 电脑重新上传包含`boards[].hidden`的索引，手机再次同步 |
| 视频不能播放 | 媒体原链接是否可访问，格式是否被手机浏览器支持 |

本轮浏览交互已通过3200条模拟数据、手机浏览器回归及项目测试；实际iPhone新交互仍需部署后使用确认。电脑采集器、文章库及开发依赖不包含在本发布仓库内。

图片张数以原图列表为准；COS或本地缩略图作为同一张图片的加载回退，不额外计数。原图失效时可回退到可用预览，清晰度取决于备用图片。
